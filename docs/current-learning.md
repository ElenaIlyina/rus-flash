# Оценки, статусы, прогресс и настройки

Реализация на **27.10.2026**, профиль `learning-score-v1`. Принципы согласованы
автором в переписке после обсуждения `author-approval-questions.md`.
Педагогическая эффективность пока не проверена; показатель не является
вероятностью знания или прогнозом балла ЕГЭ.

## Результат завершённого решения

Назначение — работа с одной карточкой от открытия/«Начать новую попытку»
до верного ответа. Каждая непустая отправка увеличивает счётчик n.
Ошибки сохраняются в истории, но оценка меняется **один раз**, при верном ответе:

| Результат | Число r |
|---|---:|
| Верно с первой попытки, без помощи | 1 |
| Верно не с первой попытки, без помощи | 1/n |
| Верно с подсказкой, просмотром ответа или разбора | 0 |

Чтение правила, включая переход к параграфу источника, не снижает результат.
Подсказка к способу решения считается помощью, даже если не содержит ответа.
Пустая отправка не является попыткой. Уход после ошибки без завершения
не меняет оценку; после возвращения счётчик продолжается.
Повторное нажатие «Проверить» после завершения не создаёт второй результат.

«Начать новую попытку» сбрасывает счётчик и помощь. Можно сразу после разбора
решить ту же карточку заново и получить 1 — по решению автора мы доверяем ученику.
Открытие разбора после уже завершённого решения не меняет сохранённый результат.
Это учебная система, не защищённый экзамен.

## Числовые оценки

У карточки до первого допустимого результата **null**, а не 0 и не оценка темы.
Первый результат задаёт оценку карточки напрямую. Следующие результаты:

```text
cardNew = (cardOld + cardA × r) / (1 + cardA)
```

Оценка темы (сейчас одна из 27 групп ЕГЭ) начинается с 0:

```text
weight = 1 для задания ЕГЭ, simpleWeight для упражнения на правило
если weight > 0:
    topicNew = (topicOld + topicA × weight × r) / (1 + topicA × weight)
```

Вес меняет силу влияния на тему, а не максимальный результат упражнения.
При simpleWeight=0 простые упражнения не меняют оценку темы и её срок повторения.
Оценка самой карточки не взвешивается по сложности. `exerciseKind: "simple"`
в метаданных каталога обозначает простое упражнение; отсутствие признака — ЕГЭ.
Пула собственных простых упражнений пока нет, контракт проверен на фикстуре.

Одна карточка может проверять разные правила; нынешняя оценка группы
не доказывает знание каждого из них. Детальная модель навыков остаётся целью.

## Значения по умолчанию и настройки

Ссылка «Настройки обучения» есть на странице прогресса и в окне о приложении.
Прямая ссылка — `#settings`. Модуль: `html/js/settings.js`.

| Свойство | Значение | Смысл |
|---|---:|---|
| cardA | 1.5118864315… | Карточка реагирует сильнее: новый результат получает около 60% веса |
| topicA | 0.5848931925… | Тема меняется плавнее: новый результат ЕГЭ получает около 37% веса |
| masteryThreshold | 0.75 | «Получается» при **строго большем** значении; ровно 0.75 — «Практикую» |
| reviewDays | 7 | Срок перехода «Получается» → «Пора повторить» |
| simpleWeight | 0.5 | Начальный выбор реализации: простое упражнение влияет на тему слабее; 1 уравнивает веса |

Точные коэффициенты и simpleWeight=0.5 — настраиваемые начальные значения,
а не выведенные экспериментально константы. Автор согласовал разные коэффициенты,
более сильное влияние результата для карточки и разные веса простого/ЕГЭ.

Если после N новых результатов нужно сохранить долю p старого значения:

```text
a = p^(-1/N) − 1
оставшийся вклад = (1 / (1 + a))^N
```

Для карточки выбран p=0.0001 (0.01%) после 10 следующих результатов,
для темы p=0.01 (1%) после 10 результатов ЕГЭ. Пресеты 1%, 0.1%, 0.01%
применяются к карточкам и темам отдельно. При заданном a увеличение его
значения усиливает новый результат. На долю темы при смешанных весах
влияют все множители `1 / (1 + topicA × weight)`.

Допустимые диапазоны: a от 0.0001 до 1000, порог от 0 до 1,
срок от 0.1 до 3650 дней, simpleWeight от 0 до 1. Конкретные значения
карточки и темы можно менять независимо; cardA > topicA задано по умолчанию.
Кнопка «По умолчанию» заполняет форму; применение — «Сохранить настройки».

Стрелки клавиатуры и кнопки ↑/↓ рядом с полем используют одинаковые шаги:
порог — 0.01, вес простых упражнений — 0.05, срок — 1 день,
оба коэффициента — 0.01. На границах значение ограничивается min/max.
При изменении стрелкой результат округляется до 12 знаков после запятой,
чтобы не показывать артефакты двоичной арифметики. Ручной ввод и пресеты
сохраняют исходную точность; step="any" остаётся только для их допустимости,
а стандартные браузерные кнопки с шагом 1 заменены явными контролами.


Настройки хранятся в `slovo_learning_settings_v1` в текущем браузере.
Изменение настроек **пересчитывает всю историю** по новому профилю, не меняя события.
Настройки не включены в файл прогресса и не перезаписываются при импорте:
для одинаковых оценок на устройствах нужно выставить одинаковые настройки.

## Статусы карточки и темы

Карточка и тема имеют **собственные** оценки и сроки:

- «Не пробовал»: нет попыток по карточке/по карточкам темы.
- «Практикую»: попытки есть, оценки ещё нет или она не выше порога.
- «Получается»: текущая оценка выше порога, срок повторения не наступил.
- «Пора повторить»: оценка выше порога и срок наступил (граница включительна).

После нового результата, сохранившего оценку выше порога, срок заново
отсчитывается от времени этого результата. Если оценка стала не выше порога,
статус — «Практикую», срок сбрасывается. Календарное время само оценку не снижает.
Незавершённые ошибки не меняют оценку и срок; это осознанное следствие
обновления по завершению, а не по каждой неверной отправке.

Карточка может получить «Получается» после первого результата 1, пока тема
остаётся «Практикую». Это заменяет прежнее наследование статуса группы.
Четыре правильных результата ЕГЭ подряд поднимают тему от 0 выше 0.75
при настройках по умолчанию. Требований трёх разных карточек, двух сессий,
24 часов и сброса после двух ошибок в новой модели нет.

## Допуск материалов и старая история

В расчёт оценок входят только карточки с `eligibleForProgress` и события,
чей materialVersion совпадает с текущей версией. История и охват при изменении
материала сохраняются. Ручные «изучено», избранное и «Повторить позже» не
поднимают оценку. Историческая проверка answer_verify не заменяет приёмку учителем.

В старых событиях без scoringVersion самостоятельный правильный ответ
без assisted интерпретируется как результат 1. Из assisted нельзя восстановить,
была ли помощь или повторная отправка и сколько их было: такие старые события
сохраняются в истории/охвате, но **не получают выдуманную числовую оценку**.
Это ограничение миграции явно отделено от новых нулевых результатов с помощью.
События с иной версией материала не используются ни в одном случае.

## Охват и закрепление

Охват = уникальные карточки с любой попыткой / весь каталог (сейчас 2140).
Одна карточка учитывается один раз; помощь и незавершённое решение дают охват.
Закрепление = группы «Получается» + «Пора повторить» / 27.
Проценты округляются вниз. Группы без готового пула не исчезают из знаменателя.
Полоса на главной отражает **статусы карточек**, а не среднее арифметическое оценок.

## События и перенос

Существующий ключ истории `rusflash_learning_v1` сохранён. Новые события имеют
scoringVersion=1, assignmentId, attemptNumber, completed наряду с прежними полями.
Завершение выводится из правильного ответа; подсказка влияет на r, не на correct.
Расчёт защищён от повторного учёта одного assignmentId одной карточки.

Счётчик, ID назначения, флаг завершения и помощи переживают перезагрузку
в `slovo_assignment_<ID>`. Назначения не переносятся между устройствами.
Файл прогресса теперь schemaVersion=2; старые v1 принимаются.
[Подробный контракт](specification/progress-transfer.md).
