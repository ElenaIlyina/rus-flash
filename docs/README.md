В документации различаются реализованное поведение, согласованные цели,
предложения и открытые вопросы. Статус «согласовано» не означает наличие кода.
Карточки и ответы ещё не прошли полную редакторскую проверку. RAG, полная нормативная база правил,
полный адаптивный маршрут, детализация мелких навыков, PWA и серверная синхронизация
не подключены.

Скриншоты не хранятся в документации. Проверки с `--screenshots` записывают
файлы в `/tmp/rus-flash-screenshots/`. Текущий интерфейс и сценарии описаны
в [маршруте проверки](interface-review.md); история вариантов доступна в Git.
