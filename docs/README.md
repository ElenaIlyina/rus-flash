В документации различаются реализованное поведение, согласованные цели,
предложения и открытые вопросы. Статус «согласовано» не означает наличие кода.
Карточки и ответы ещё не прошли полную редакторскую проверку. RAG, база правил,
адаптивный маршрут, системное оценивание навыков, PWA и серверная синхронизация
не подключены.

Изображения в composed-home/, progress-preview/ и ui-preview/ обновляются
браузерными тестами с `--screenshots`. Снимки в design-directions/ — архив.
В bank-review/ сохранён прежний этап оформления; card-layout/ показывает
выделение текста и задания. Изображения не заменяют проверку действующего сайта.
