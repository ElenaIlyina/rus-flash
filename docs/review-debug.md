# Отладочное ревью карточек

Режим предназначен для локальной проверки материалов. По умолчанию выключен.

## Включение

1. «Мой прогресс» → «Настройки обучения» (прямая ссылка `#settings`).
2. Раскрыть «Отладка» и нажать «Включить ревью карточек».
3. Открыть «Очередь ревью». Ссылка также появится над банком.

В очереди `#debug` есть фильтры «На ревью», «Есть замечания», «Приняты», «Все».
Показываются подготовленные разборы из двух реестров и карточки с явно
зафиксированными замечаниями. Это не автоматический diff всей ветки:
карточки без разметки ревью и замечаний туда не подставляются.

В банке видны отладочные метки, в карточке — панель с составом проверки
(объяснение, подсказка, источники, согласованное условие) и открытыми замечаниями.

## Локальное принятие

«Разбор принят» сохраняет хеш версии под ключом карточки в этом браузере.
«Вернуть на ревью» снимает отметку. Хеш учитывает исходную карточку, объяснение,
индивидуальную подсказку, разметку рядов, связанные правила и тексты источников,
а также замечания. После изменения материала старая отметка не подходит.
Новая сборка данных читается после обновления страницы.

Принятие не закрывает замечания, не разрешает менять условие и не является
предметной приёмкой учителем. Оно не изменяет события обучения, оценки,
избранное или экспорт прогресса. Настройка и отметки локальны и в Git не пишутся:
`slovo_review_debug_v1`, `slovo_review_acceptances_v1`.

В выключенном режиме нет меток, панели и очереди; файл review-debug.json
не загружается. Прямой переход на #debug показывает, что отладка выключена.
Это переключатель интерфейса, а не авторизация или защита редакторских данных.

## Источники данных

- `prefix_card_reviews.json` и `root_card_reviews.json` — подготовленные разборы.
- `review_issues.json` — открытые замечания для отладочного интерфейса.
- `content_review_overrides.json` — существующие блокирующие дефекты.
- [Очередь замечаний](content-audit/open-issues.md) — подробности и история.

При закрытии замечания обновляются и документ, и review_issues.json.
Сборка пишет отдельный лениво загружаемый review-debug.json.
Проверка: `python3 tests/review_debug_smoke.py`.
