# Предпросмотр прогресса: охват и закрепление

## Как открыть

На ветке `feat/slovo-za-slovo` обновить код, собрать данные и запустить HTTP-сервер по README. Открыть **«Мой прогресс»**: сразу показывается реальный прогресс; демо открывается по ссылке «Пример дашборда». Реальные действия — по кнопке **«Моя реальная история»**. Прямой маршрут внутри приложения: `#progress?view=preview`.

Это интерактивная иллюстрация будущего отображения, не новый алгоритм оценки учеников. Метка «ДЕМО» и предупреждение видны на каждом демонстрационном экране. Существующая реальная история и экспорт сохранены отдельно.

## Представление

- Главный показатель: закрепление, 9 из 24 навыков, 38%.
- Второй показатель: охват, 17 из 24, 71%.
- Короткое предложение вернуться к навыкам с наступившим сроком; достижение не обнуляется.
- Четыре крупные темы, по одной сегментированной полосе; одна легенда с численностью статусов.
- Нажатие на тему открывает шесть демонстрационных навыков. Каждый раскрывается в объяснение статуса.
- Связанные правила, упражнения и самооценка обозначены как будущая интеграция. Кнопка банка открывает текущую тему без ложного утверждения о точном соответствии выбранному навыку.
- Редакторская готовность банка объясняется отдельно от результатов ученика.

## Переключаемые примеры

| Пример | Получается / пора повторить / практикую / не пробовал | Закрепление | Охват |
|---|---|---|---|
| Есть первые результаты | 6 / 3 / 8 / 7 | 9/24 = 38% | 17/24 = 71% |
| Наступило повторение | 4 / 5 / 8 / 7 | 9/24 = 38% | 17/24 = 71% |
| В самом начале | 0 / 0 / 0 / 24 | 0/24 = 0% | 0/24 = 0% |

Пример «в самом начале» означает настроенный модуль из 24 навыков без попыток. Это не случай отсутствующей модели навыков: в реальном приложении такая модель ещё не подключена, поэтому настоящий процент освоения не вычисляется.

## Данные и границы

`html/js/progress-preview.js` содержит фиксированные примеры и вычисляет агрегаты из распределения, не подставляет проценты вручную. Классификация этих 24 навыков иллюстративна, не является утверждённой программой ЕГЭ-2027.

Модуль не импортирует store, не читает и не записывает учебные события. Визуальные переключения меняют только URL. Целевой сервис проекций в будущем заменит фикстуру результатами редьюсера навыков; оценивание, версии, качество и расписание должны соответствовать [спецификации](specification/README.md).

## Проверка и снимки

`python3 tests/progress_preview_smoke.py` проверяет формулы примера, сохранение процента при наступлении срока, начальное состояние, раскрытие тем/оснований, возврат в реальную историю, отсутствие изменений localStorage и переполнения на ширинах 320/390/768/1440. `--screenshots` обновляет снимки:

- [Обзор на компьютере](progress-preview/overview-1440.png).
- [Обзор на телефоне](progress-preview/overview-390.png).
- [Тема и основание статуса](progress-preview/skills-1440.png).

Это проверка интерфейсной гипотезы и примеров формул, не проверка педагогического алгоритма на реальной истории. Полосы имеют текстовые описания для вспомогательных технологий, статусы различаются подписями и штриховкой. Реальные Safari/Android пока отдельно не проверялись.
