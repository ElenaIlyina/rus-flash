# Ревью нового интерфейса

## Что реализовано

Ветка `feat/adaptive-interface`. План — отдельный первый коммит; реализация интерфейса — следующий. Внешняя публикация и Pull Request не создавались автоматически.

- Главная с началом/продолжением занятий, темами и честными показателями.
- Банк из существующих 2140 карточек, поиск, фильтры, выдача порциями по 24.
- Карточка без iframe: текст отдельно от инструкции, ограниченная безопасная разметка, варианты, ответ, объяснение.
- При явно заданном bitmask — чекбоксы, иначе сохранена прежняя проверка краткого ответа. Новые типы не угадываются по номеру.
- Избранное, повторение, ручная отметка «изучено». Старые метки не удаляются.
- Новая история попыток с отличием самостоятельного решения от подсказки/повторной попытки.
- Прогресс на основе реальных действий, экспорт JSON. Никаких вымышленных баллов, серий занятий и «освоения».
- Навигация назад/вперёд, старые ссылки ?id и ?task, ошибки загрузки и пустые результаты.
- Светлый адаптивный дизайн, внешние CSS/JS, системные шрифты, локальные SVG.
- Данные карточек подгружаются по одной, исходные JSON не изменены.

## Чего пока нет

- Подтверждения материалов и нумерации ЕГЭ-2027. Пользовательское пожелание 3→2→1→3 зафиксировано в плане; слепая перенумерация не выполнялась.
- Проверенной базы знаний и ссылок на правила. Экран справочника объясняет отсутствие материалов.
- RAG, модели и ключей. Это будущий редакторский инструмент, не вызов модели из браузера.
- Автоматического адаптивного подбора. Кнопка открывает описание будущего режима, а не выдаёт случайные карточки под видом персональных.
- Аккаунтов, сервера синхронизации и офлайн-PWA. Импорт JSON добавлен позднее: см. контракт переноса прогресса.
- Формы отправки ошибок: выводится ID и объясняется, что сообщения не отправляются.
- Массовой миграции типов ответов, нормализации и структурированных текстов. Это отдельный этап.

## Точки интеграции

`html/js/services.js` задаёт асинхронные интерфейсы `knowledge.findRules`, `knowledge.getRule`, `adaptive.recommend`, `sync.push`. Справочник и кнопка правила карточки обращаются к knowledge; адаптивная кнопка — к recommend. Sync не вызывается, пока нет явно включённого сервиса и пользовательского согласия. Данные не покидают браузер.

Заглушки не являются завершёнными реализациями API. При подключении сервиса потребуется обработка результатов, ошибок, состояний загрузки и дополнительные проверки. Статус готовности и отсутствие материалов должны оставаться видимыми.

Адаптер `data.js` — граница между исходной моделью и интерфейсом. Можно добавить passages, response и review по новой схеме, сохранив экраны. HTML исходных полей проходит белый список тегов без атрибутов; исходники сохраняются неизменными.

## Маршрут ручного ревью

1. Собрать `bash scripts/install.sh`, запустить сервер из README.
2. На главной оценить иерархию, цвета, плотность, читаемость и переходы.
3. В банке поискать 012CAB, поставить избранное/повторение, проверить соответствующие фильтры.
4. Решить карточку, посмотреть ответ и разбор, перейти к правилам и вернуться назад.
5. Открыть 06A9D8: оценить отдельный текст и варианты. 03ADF2 — таблицу соответствий.
6. Выбрать фильтр «Без ответа»: убедиться, что ложная автопроверка отсутствует.
7. Открыть прогресс и экспорт. Правильная повторная попытка не считается самостоятельной.
8. Повторить на ширине 390 и 320 px; проверить клавиатуру, фокус, масштабирование, длинные тексты.
9. Сравнить старый интерфейс: legacy.html. Он сохранён намеренно, не является финальным релизным содержимым.

## Ограничения измерений

При первом измерении HTML/CSS/JS и каталог вместе занимали около 132 КБ gzip; итоговый размер может немного измениться. Это размер при сжатии на хостинге, а не доказательство скорости на реальной мобильной сети. Python http.server не включает gzip автоматически. Тесты Chromium не заменяют проверку Safari/iPhone и Android на реальных устройствах.

Браузерные сценарии подтверждают работу интерфейса с текущими данными, но не правильность учебных ответов и не эффективность адаптивного обучения.


## Обновление банка заданий

В #bank убрана строка-предупреждение о прежней классификации; это изменение интерфейса, а не подтверждение нумерации 2027. Слева у задания теперь номер группы, в строке — ID карточки. Фильтр «⭐ Избранное» становится жёлтым при выборе, у сохранённых карточек видна звезда. Фильтр «⏳ Повторить» сохраняет прежний отбор по метке hard. [Компьютер](bank-review/bank-1440.png) · [Телефон](bank-review/bank-390.png). Проверки включены в tests/ui_smoke.py.


## Разделение содержимого карточки

Исходный текст выделен голубым фоном и синей вертикальной полосой; условие — светло-жёлтым блоком; варианты — белыми отдельными строками. Заголовки «Текст к заданию», «Задание» и «Варианты к заданию» сохранены: смысл не передаётся только цветом. Проверена карточка 0ABFEC, раскрытие текста и мобильная компоновка. Данные и смысловые выделения не изменены. [Компьютер](card-layout/0ABFEC-1440.png) · [Телефон](card-layout/0ABFEC-390.png).

## Навигация отдельными страницами

Разделы перенесены с hash-маршрутов на отдельные HTML-документы.
Внешний вид сохраняется; общая оболочка собирается из одного шаблона.
Актуальные адреса и поведение описаны в [архитектуре](specification/architecture.md).
