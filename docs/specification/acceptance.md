## Текущая числовая политика после согласования автора

AC-05–08 выше описывают прежний профиль v0; теперь вместо них действуют:

| ID | Дано / действие | Ожидаемый результат |
|---|---|---|
| AC-S01 | Новая карточка, первый правильный ответ | Оценка карточки 1, «Получается»; тема обновлена от 0, остаётся «Практикую» при значениях по умолчанию |
| AC-S02 | Ошибка, перезагрузка, чтение правила, верный ответ | Одна завершённая оценка 1/2; чтение правила без штрафа |
| AC-S03 | Подсказка, перезагрузка, верный ответ | Завершённый результат 0; помощь не забывается |
| AC-S04 | После AC-S03 нажать «Начать новую попытку» и ответить верно | Новый результат 1, карточка сглаживается от 0, не инициализируется заново |
| AC-S05 | Повторно проверить уже завершённое решение | Нового события/оценки нет |
| AC-S06 | Оценка ровно 0.75 / выше 0.75 | «Практикую» / «Получается» |
| AC-S07 | Прошло ровно 7 дней после обновления оценки выше порога | «Пора повторить»; закрепление сохраняется |
| AC-S08 | Сохранить другие коэффициенты, порог и срок; перезагрузить | Значения сохранены, история пересчитана по настройкам |
| AC-S09 | Старое событие assisted=true без счётчика | Есть в истории/охвате, не получает выдуманного результата 1/n или 0 |
| AC-S10 | Один assignment завершён дважды с разными event ID | Расчёт использует один результат |
| AC-S11 | Простое упражнение с weight=0 / 0.5 / 1 | Не меняет тему / слабее влияет / влияет как ЕГЭ; оценка карточки по r |
| AC-S12 | Экспорт новых событий v2 и повторный импорт | Поля сохранены, нет повторного начисления; v1 также принимается |

Подробные определения и формулы — в [текущей политике](../current-learning.md).
Часть сценариев проверяется на фикстурах, пока простых упражнений в банке нет.

## Разделение проверок

- **Схема/сборка:** ID, ссылки, версии, отсутствие циклов, соответствие типов ответов политикам.
- **Unit:** оценивание, редьюсер статусов, выбор следующего шага, формулы и округление.
- **Интеграционные:** миграция, отзыв эталона, восстановление после перезапуска, запись/воспроизведение событий.
- **Браузерные:** понятные состояния, клавиатура, мобильная вёрстка, помощь и формы.
- **Предметные:** правильность материалов и диагностических соответствий подтверждает учитель/редактор.
- **Исследовательские:** сравнение обучения по зафиксированной методике; unit-тест не доказывает педагогическую эффективность.
