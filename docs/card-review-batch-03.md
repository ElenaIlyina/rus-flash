## Как проверить

Включить [отладочное ревью](review-debug.md). В банке искать карточку по ID,
открыть подсказку, разбор и источники по рядам. «Разбор принят» — локальная
отладочная отметка текущей версии; она не публикует редакторское решение.

```bash
bash scripts/install.sh
python3 scripts/review_prefix_explanations.py --group roots
python3 tests/handbook_test.py
python3 tests/content_audit_test.py
python3 tests/review_debug_smoke.py
python3 tests/bank_knowledge_smoke.py
```
