# Выбор надёжного справочника

Сверено 27.10.2026 с присланным официальным **проектом** кодификатора ФИПИ-2027.

## Подтверждённые библиографические источники

В конце кодификатора есть раздел «При составлении кодификатора и разработке
заданий использованы следующие источники». Это список использованных изданий,
а не включённые в архив полные тексты книг.

| Назначение в проекте | Точное издание из списка ФИПИ | Где подтверждено |
|---|---|---|
| Основной источник орфографии и пунктуации — предлагаемый выбор | Правила русской орфографии и пунктуации. Полный академический справочник / под ред. В. В. Лопатина. — М.: АСТ-Пресс, 2020 | «Другие источники», пункт 4, печатная стр. 18 |
| Дополнительные правила и практическая стилистика | Универсальный справочник по русскому языку: Орфография. Пунктуация. Практическая стилистика / Д. Э. Розенталь. — М.: Мир и Образование, 2015 | Пункт 19, стр. 18 |
| Историческая нормативная основа | Правила русской орфографии и пунктуации: утв. АН СССР, Мин-вом высшего образования СССР, Мин-вом просвещения РСФСР / Л. В. Щерба и др. — М., 1956 | Пункт 5, стр. 18 |
| Ударения, отдельный словарь | Большой орфоэпический словарь русского языка / Л. Л. Касаткин, Р. Ф. Касаткина, М. Л. Каленчук. — М.: АСТ-Пресс, 2021 | Пункт 1, стр. 17 |

Дополнительно в кодификаторе перечислены государственные словари и словари
паронимов. Один справочник орфографии не покрывает весь банк: для ударений,
паронимов и значений слов нужны соответствующие источники.

## Ссылки и сохранённое подтверждение

- [Официальная страница ФИПИ](https://fipi.ru/ege/demoversii-specifikacii-kodifikatory).
- [Официальный архив проекта-2027](https://doc.fipi.ru/ege/demoversii-specifikacii-kodifikatory/2027/ru_11_2027.zip).
- [Копия кодификатора](references/ege-2027/codifier.pdf), печатные страницы 17–19.
- [Реестр URL и хешей PDF](references/ege-2027/sources.json).

Сайты справочников (Грамота.ру, ресурсы академических правил) не удалось
прочитать из этой среды: CONNECT прокси вернул 403. Поэтому ссылка на конкретный
непрочитанный веб-параграф не выдаётся за проверенное основание. Электронный
текст книги Лопатина ещё не получен; владелец предложил помощь со скачиванием.
При получении сверить титульный лист, год, полноту и SHA-256, затем сопоставить
параграфы, а не переносить нумерацию из другого издания автоматически.

## Связь с локальным справочником

Первые четыре параграфа data/knowledge/handbook.json — авторские черновики.
Им не присваивается статус «проверено по Лопатину», пока текст выбранного
издания не прочитан и не выполнено сопоставление. Уже работают постоянные
ссылки #knowledge?rule=<id>, контекст карточки и учёт помощи.

При сверке добавить к параграфу editionId, номер раздела/параграфа и страницу,
sourceUrl, точное основание и статус предметного ревью. Сохранить собственный
id параграфа для устойчивости ранее выданных ссылок. Номера локальных §1–4
сейчас не являются номерами параграфов академического издания.

теория, рекомендации, упражнения и/или ссылки на другие источники.
