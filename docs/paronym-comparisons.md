# Сопоставление паронимов в разборе

Актуально на **29.10.2026**. Требование автора: определения, примеры и
обоснование замены должны быть сверены с конкретными словарными статьями.
Названия книг в библиографии и список слов ФИПИ не заменяют такую сверку.

## Текущее состояние

| Карточка | Сравнение | Состояние |
|---|---|---|
| 012CAB | лакированный / лакировочный / лаковый | Статьи проверены; оценивание по ключу «лакировочным», словарное «лаковым» остаётся примечанием |
| 01C2C7 | враждебный / вражеский | Статьи и опубликованный разбор проверены; ответ «вражеский» остаётся доступен для проверки |

Получены два полных пользовательских PDF: нормативный словарь с адреса
ruslang.ru и Вишнякова, 1984. Прочитаны выбранные статьи, не все словари.
[Отчёт со страницами, выходными данными и ограничениями](paronym-source-review.md).
Остальные **112 карточек №5** пока без словарного допуска: их пояснения
и индивидуальные семантические подсказки не публикуются, ответы сохранены.

В разборе слова располагаются рядом, на телефоне — друг под другом.
У каждого слова — краткое значение, примеры и ссылки на фактические
страницы PDF. Ниже — различие, применение к предложению и форма ответа.
Открытие сравнения через «Ответ и разбор» считается помощью по действующей
политике. Полные PDF загружаются отдельно по ссылке на источник.

## Структура данных

`data/knowledge/paronyms.json` содержит:

- `sources`: ID словаря, оригинальный файл, SHA-256, число PDF-страниц,
  подтверждённые выходные данные и происхождение;
- `pairs`: стабильный ID сравнения, массив `words`, поле `distinction`;
- у слова: `meaning`, `examples`, `dictionaryRefs`;
- у ссылки: `dictionaryId`, `headword`, `pdfPage`, `printedPage` или null,
  `definitionQuote`, способ визуальной проверки и дата;
- `curriculumRef`: место в списке ФИПИ; оно подтверждает перечень слов,
  а не их значения;
- `reviewStatus`: `verified` только после чтения статей.

`ege_1_6_card_reviews.json` связывает карточку и сравнение через
`paronymPairIds`. В `dictionaryReview` указываются статус, ссылки и область
сверки. Допуск касается опубликованного объяснения; он не означает, что
перепроверены все исходные варианты или все принимаемые сервером ФИПИ ответы.

`printedPage` не заполняется по догадке. Для электронной перевёрстки
Вишняковой известны PDF-страницы; страницы печатного издания не установлены.
Отсылки между статьями разрешаются явно: у «лакировочный» сохранены ссылки
на его статью и на определяющую статью «лакировальный».

## Проверки публикации

`scripts/paronym_sources.py` проверяет хеши оригиналов, ID источников,
диапазоны страниц, наличие слова, цитаты-основания и отметки визуального
чтения. Это защита от неполной/устаревшей разметки, а не автоматическое
доказательство истинности словарной интерпретации.

Сборка разрешает пояснение №5 только при `dictionaryReview.status = verified`
и действительных `sourceRefs`. Для самого сравнения дополнительно нужен
`reviewStatus = verified` и проверенные ссылки у каждого слова.
Без допуска исходные пояснения остаются в `data/`, а runtime-поле объяснения
пусто. На сайте в таком случае кнопка называется «Показать ответ».

PDF копируются в игнорируемый `html/assets/data/dictionaries/`, для открытия
используется URL с `#page=N`. Отдельный запрос к исходному сайту не требуется.
Хеши словарей и данные сравнения включены в версию отладочного ревью.

По решению автора автоматическое оценивание соответствует ключам ФИПИ.
Допустимое словарное сочетание само по себе не расширяет принимаемые
ответы и не отключает проверку. Для 012CAB принимается «лакировочным»;
«лаковым» поясняется как лексически допустимое, но не засчитывается в этом
задании. Временная блокировка 012CAB снята. Словарные расхождения сохраняются
в редакторском журнале отдельно от правил оценивания.

## Дальнейшая работа

Продолжать №5 с этим форматом. У паронима может быть больше одной пары,
у слова — несколько значений. Не превращать контекстное различие в запрет
всех пересечений значений. Не переносить старые пометы на современную
редакцию без сверки. Для каждой новой карточки сохранять статью, нужное
значение, страницу и основание выбора; спорные ответы вести отдельно.

[Литература для дальнейшего поиска](Список%20литературы.md).

Проверки: `paronym_sources_test.py`, `priority_1_6_smoke.py`,
`content_audit_test.py` и `check_pages_artifact.py`.
