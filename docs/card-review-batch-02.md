# Разбор карточек: партия 02

28.10.2026. Ветка `feat/card-explanations-02`, основана на main после слияния.

## Границы

Автор разрешил заменять объяснения. Условия, исходный текст, варианты, ответы,
answer_verify, GUID и КЭС меняются только после отдельного согласования.
В этой партии они не менялись: Git-сравнение JSON подтверждает, что у пяти
изменённых карточек отличается исключительно поле explanation.

В группе 10 найдены ровно 12 карточек с исторически проверенными ответами,
допущенных к расчёту прогресса. Все уже входят в первую партию.
Следующий модуль — группа 9, корневые гласные. Выбраны четыре карточки с пропусками
и сохранёнными историческими ключами; новый запрос к ФИПИ не выполнялся.

| Карточка | Сохранённый ответ | Работа |
|---|---|---|
| 0C24B0 | 25 | Все пять рядов, проверяемые/чередующиеся гласные, И после Ц; индивидуальная подсказка |
| 1A1A4B | 135 | Все пять рядов, ЛАГ-/ЛОЖ-, БЛЕСТ-/БЛИСТ-, различение «гореть» и «горячий»; индивидуальная подсказка |
| 279C1A | 15 | Все пять рядов, проверка ударением и ТЕР-/ТИР-; индивидуальная подсказка |
| 2AFA71 | 23 | Все пять рядов, смысл слова при проверке, РАСТ-/РАЩ-/РОС-, ЛАГ-/ЛОЖ-; индивидуальная подсказка |

Дополнительно по замечанию автора **полностью переработана 003B4D**:
это распознавание проверяемых гласных в готовых словах, не заполнение пропусков.
Отдельная подсказка соответствует инструкции, объяснение разбирает все пять
рядов. Заглавных букв внутри слов нет; проверочные слова показывают ударение
(«шелестеть — ше́лест», «седина — се́д»). Это не замена слов в variants.
В реестре теперь пять карточек: четыре same_letter_gap и одна checked_root_vowels.
Хеш-цепочка всех изменений дополнена, прежние записи сохранены.

## Источники и реализация

Лопатин (ред.), Эксмо, 2007: орфография §16, §§33–36. Полученный FB2,
метаданные и хеши уже хранятся в проекте. Ссылки по рядам открывают локальный
параграф. Номер нашего короткого правила не заменяет книжный номер.

Три новых коротких правила: проверяемые гласные, чередования, использование
словаря. Для непроверяемых написаний §34 объясняет метод: это не словарная
статья на каждое слово. Историческое совпадение выбранных рядов с ключом
не выдаётся за независимую словарную сверку каждого восстановленного слова.
Разборы имеют статус ассистентского редакторского черновика, не приёмки учителем.

- [Разметка рядов и подсказок](../data/knowledge/root_card_reviews.json).
- [Короткие правила](../data/knowledge/handbook.json).
- [История изменений объяснений](content-audit/explanation-reviews.json).
- [Нестыковки для дальнейшей работы](content-audit/open-issues.md).

Индивидуальная подсказка загружается вместе с метаданными карточки;
при отсутствии используется прежняя стратегия группы. Открытие подсказки
сохраняет прежнюю семантику помощи. В подсказке нет номера правильного ряда
или готового ответа.

Реестр фиксирует SHA-256 всех полей карточки, кроме explanation. Скрипт
отказывается воспроизводить разбор при изменении исходного задания: нужны
согласование автора и повторная проверка разметки.

## Проверки

```bash
python3 scripts/review_prefix_explanations.py --group roots
python3 tests/handbook_test.py
python3 tests/content_audit_test.py
bash scripts/install.sh
python3 scripts/check_pages_artifact.py html
python3 tests/bank_knowledge_smoke.py
python3 tests/ui_smoke.py
```

Команда проверки разборов по умолчанию не пишет файлы. `--write` применяет
проверенную партию и дополняет журнал; исходные поля задания не переписывает.
Аргумент `--group roots` выбирает новый реестр, без аргумента остаётся первая
партия приставок для совместимости. Все поля заданий дополнительно сверены
с базовым коммитом через Git.
