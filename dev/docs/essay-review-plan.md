# Предварительная проверка сочинения №27

Статус на 21.11.2026 — договорённости для будущей отдельной ветки. Цель пилота — дать каждому ученику обратную связь по сочинению на его устройстве.

## Подключение ученика

- По обычной ссылке при первом посещении сайт открывается в режиме без модели. Доступны карточки, пробники и сочинение. Модель включается после подтверждённого подключения и доступна при следующих посещениях в том же браузере. Сочинение отправляется только по кнопке «Проверить сочинение».
- **Ссылка-приглашение** — один из способов подключения. Сайт показывает HTTPS‑адрес сервера и сохраняет его после подтверждения. Альтернатива — вручную ввести выданный адрес в настройках. На другом устройстве подключение нужно повторить.
- Адрес хранится в настройках браузера, например в `localStorage`. В репозитории хранится код подключения. Адрес сервера можно сменить или убрать из настроек. Для школьного пилота предусмотрены индивидуальные коды доступа с лимитом проверок.

## Где работает модель

- Для класса планируем отдельный Linux‑сервер с HTTPS‑обработчиком `/check-essay`. Интерфейс остаётся на GitHub Pages. Сервер принимает ID карточки и сочинение, находит исходный текст, добавляет критерии и промпт, вызывает модель и возвращает структурированные замечания. CORS разрешает нужные адреса GitHub Pages. Доступ и лимиты проверяет сервер.
- При облачной модели серверу достаточно передавать запросы провайдеру. Ключ хранится на сервере вне репозитория и каталога сайта, например в защищённом файле с передачей службе через `systemd LoadCredential=`. Адрес сервера доступен ученику, ключ провайдера доступен службе. Промпт хранится на сервере. Провайдер получает сочинение, исходный текст и выдержки из критериев без имени ученика и истории прогресса. [Документация systemd](https://www.freedesktop.org/software/systemd/man/latest/systemd.exec.html#Credentials)
- Для локального прототипа используем Ollama и Gemma 4B как отправную точку. Замеряем скорость на полном запросе и проверяем качество на русскоязычных сочинениях. [Ollama](https://docs.ollama.com/api/introduction)
- **WebLLM** остаётся отдельным вариантом подключения. Ученик выбирает запуск в браузере. Сочинение обрабатывается на его устройстве, адрес сервера и подписка не нужны. Для запуска требуются загрузка модели, поддержка WebGPU и достаточная память. Доступность на Firefox под Linux и на слабых устройствах проверяется отдельно. [WebLLM](https://webllm.mlc.ai/docs/user/get_started.html)

## Промпт и проверка качества

1. Код считает слова и абзацы, находит цитаты в исходном тексте и проверяет, присутствуют ли в сочинении цитаты, приведённые моделью.
2. Готовим версионируемый промпт по [критериям ФИПИ ЕГЭ‑2027](references/ege-2027/demo.pdf) и предоставленным учебным PDF. Передаём вопрос задания, исходный текст и сочинение. Проверяем соответствие вопросу, позицию автора, примеры, связь между ними, позицию ученика, аргументацию и структуру.
3. По каждому замечанию модель возвращает критерий, точную цитату, объяснение и конкретный совет по правке. При недостатке оснований она явно сообщает об этом. Интерфейс показывает предварительный разбор. Решение об учёте №27 в показателе закрепления принимается после проверки качества.
4. Сравниваем версии промпта и моделей на наборе сочинений с учительскими разборами. Проверяем совпадения замечаний, пропущенные ошибки, ложные замечания и точность цитат. Сохраняем примеры ошибок модели для повторной проверки.
