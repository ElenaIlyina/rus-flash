## Как классифицировать карточку

1. Определить действие по инструкции: выбрать, вписать, установить соответствие, написать сочинение.
2. Проверить материал и варианты: корень/приставка/суффикс, типы речи/содержание, значение/извлечение слова.
3. Использовать КЭС как дополнительное свидетельство, а не уникальный ключ позиции.
4. Сверить формат с демоверсией. Старую форму пометить отдельно; сходство темы не означает совпадение экзаменационного формата.
5. Сохранить основание и статус ручного разбора для неоднозначных карточек. Не объявлять все карточки проверенными по факту загрузки спецификации.

## Неоднозначности и ошибки прежней раскладки

- **№1.** 1.2 встречается и в №26; различать по действию.
- **№2.** Старая словарная статья с одним словом — та же тема, но иной формат.
- **№3.** Не смешивать с анализом типов речи №24.
- **№4.** Старая инструкция найти одно неверное ударение требует отметки прежнего формата.
- **№5.** Один КЭС с №6, решает формулировка.
- **№6.** Не относить в №2 только по лексической тематике.
- **№8.** Ответ — упорядоченные соответствия, не множество цифр.
- **№10.** Комбинация 3.7.3 + 3.7.4 не является основанием относить карточку к №12.
- **№11.** Код 3.7.5 сам по себе неоднозначен: в №12 он тоже есть.
- **№12.** Смешение суффиксов и окончаний нельзя автоматически оставлять в №11.
- **№16.** Код 3.8.7 пересекается с №19, решает формат.
- **№19.** От №16 отличать по действию и структуре условия.
- **№21.** Сам факт запятой/тире ещё не задаёт №16–20.
- **№22.** Старую рецензию с пропусками нельзя выдать за идентичный современный формат.
- **№23.** Не смешивать с типами речи и логическими отношениями №24.
- **№24.** Даже если в старой карточке стоят КЭС 1.2 или 2, анализировать варианты ответов.
- **№25.** Код общий с №2; выписывание из текста отличается от выбора значения.
- **№26.** Не смешивать с подбором пропущенного слова №1.

Ранее согласованный цикл №3→2→1→3 применим только к трём соответствующим типам: значение слова → №2, подбор слова → №1, стилистика → №3. Целые прежние группы переносить циклом нельзя: в них есть лексическое редактирование (№6), типы речи (№24), лексический поиск (№25) и связь предложений (№26).

Спецификация, раздел 11, печатная стр. 16: изменения структуры и содержания КИМ относительно 2026 года отсутствуют; расширен список источников в кодификаторе. Это не делает прежнюю классификацию проекта автоматически правильной.
