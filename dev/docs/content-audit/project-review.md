## Масштаб и воспроизведение

В собранном каталоге 2140 карточек, 2069 с проверенным ключом, 2032 с опубликованным объяснением. Записи с прежним форматом и сочинения сохранены.

В Chromium сопоставлены типы ответов до и после правки для всех 2140 карточек. Изменились ровно 13. Для каждой подтверждено, что прежняя функция принимала ключ в обратном порядке, новая отклоняет его и принимает исходный. Для `00EA20` интерфейс отдельно проверен на неправильном `39618` и правильном `39681`.

Затронутые карточки №22: `00EA20`, `1E12FC`, `28B68C`, `2E29D4`, `438B08`, `5936D8`, `66CDCF`, `7442A9`, `77D7CE`, `A89897`, `B7A6D4`, `BED77C`, `FE4686`.

Учебные условия и эталоны сохранены. [Вопросы для автора и преподавателя](project-review-human-questions.md).

## Проверки

- Сборка из исходных данных и проверка комплекта Pages прошли для 2140 карточек. Сравнение с каталогом сборки исходного main показало побайтовое совпадение файлов в `html/assets/data/`. Синхронность семи опубликованных входов проверена командой `python3 dev/scripts/publish_content.py --check`.
- Полный запуск `python3 -m unittest discover -s dev/tests -p '*_test.py'` — 254 теста прошли.
- Выполнены все 32 сценария `dev/tests/*smoke.py` с Playwright Chromium. В первом прогоне прошли 30. Два сценария ожидали четыре пункта навигации и историческую блокировку 682A9C. После сверки с текущим меню и журналом решения оба прошли повторно. Проверка исключения заблокированных карточек сохранена на отдельном примере.
- Проверялись прохождение экзамена, самостоятельная и адаптивная практика, справочники, перенос истории и отображение на мобильном экране. Эти проверки подтверждают поведение приложения. Экспертная оценка всех формулировок банка требует отдельной предметной работы.
