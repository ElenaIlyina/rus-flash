# Перенос подтверждённых ответов в приложение

30.10.2026 автор разрешила перенести найденные ответы из журнала в рабочие
JSON карточек. Сайт теперь использует эти ключи после обычной сборки.

## Результат

- **2069** карточек содержат подтверждённый ответ, **71** сочинение остаётся
  без автоматического оценивания.
- Добавлены **1134** отсутствовавших ответа. Все прежние **935** основных
  ответов подтверждены и сохранены.
- У **154** прежних записей `answer_verify` заменён фактически отправленной
  и принятой строкой (например, перечень вариантов превращён в битмаску).
  Основные ответы этих карточек не заменены.
- Изменено **1290** карточек: 1134 новых ключа, 154 проверочных строки и
  две карточки с дополнительным подтверждённым ответом.
- `09C71B`: принимаются **позже** и **затем**; `432ADD`: **но** и **а**.
  Дополнительные формы отражены в разборе.
- «Потом» для 12BBAB и «лаковым/лакировальным» для 012CAB не добавлены:
  у них пока нет полученного свидетельства приёма ФИПИ.
- Условия, варианты, порядок, общие тексты, объяснения, КЭС, GUID и замечания
  этой операцией не менялись.

## Поля карточки

```json
{
  "answer": "позже",
  "answer_verify": "позже",
  "accepted_answers": ["позже", "затем"]
}
```

`answer` — основной ответ для отображения. Для выбора вариантов это список
номеров, например `235`; для соответствия порядок сохраняется.
`answer_verify` — принятая сервером строка: для пяти флажков `235` это `01101`.
`accepted_answers` необязателен; сейчас присутствует только в двух карточках
с доказанной альтернативой. Если поля нет, проверяется единственный `answer`.
Все дополнительные ответы обязательно подтверждены исходными журналами.
Имеющаяся нормализация регистра/е–ё сохранена; словарные синонимы не добавляются.

## Границы проверки

Импорт повторно собирает общий журнал из шести оригиналов, проверяет GUID,
хеши исходника, HTTP-статус, тело `3`, хеш тела и представление ответа.
Текущие условия/варианты сверяются с сырой выгрузкой; исключения повреждённых
полей допускаются только с явным `content_issue`. Непустой основной ключ,
который не подтверждён журналами, останавливает импорт для предметной сверки.
Все проверки выполняются до записи карточек.

Запуск офлайн:

```bash
python3 dev/scripts/import_verified_fipi_answers.py --check
# Повторяемый импорт без дублирования правок:
python3 dev/scripts/import_verified_fipi_answers.py --apply
python3 dev/scripts/publish_content.py
bash scripts/install.sh
```

`--check` не меняет файлы. Production-сборка не читает dev/ и журналы.
Редакторские хеши обновлены с указанием источника, без повторного предметного
ревью. Исторические планы и их хеши не менялись. По действующей политике
изменение полей карточки обновляет `materialVersion`; история попыток не удаляется.

## Проверки

Пройдены 67 модульных тестов и браузерная сверка каждого из 2069 ответов.
Проверены обе альтернативы, отказы для неподтверждённых синонимов, реальные
формы ответа, отсутствие автоматической проверки сочинения и работа значков
замечаний мышью/клавиатурой/на телефоне. Артефакт Pages пересобран и проверен.
