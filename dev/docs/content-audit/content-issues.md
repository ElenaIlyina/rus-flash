# Замечания к карточкам в интерфейсе

Решение автора от 30.10.2026. Необязательное поле карточки:

```json
{
  "content_issue": "Описание несоответствия или затруднения обычным текстом."
}
```

Поле — строка без HTML. Если его нет или строка пустая, значка нет.
Непустое значение появляется рядом с номером карточки как значок «!».
Описание открывается наведением мыши, фокусом с клавиатуры или нажатием
на телефоне. Escape, повторное нажатие или нажатие вне описания закрывают его.
Значок имеет доступное имя и связь `aria-describedby` с текстом.

Чтение замечания не считается подсказкой, не записывает попытку и не меняет
оценку или правила проверки. Замечание само по себе не выключает оценивание;
существующие ограничения доступности проверки действуют отдельно.

Отмечены восемь повреждённых записей источника и два предметных вопроса:
`044054`, `139F0C`, `39AA6F`, `7755A0`, `802933`, `BF989E`, `C96DCA`, `F8BFF9`,
`6E2A0F`, `88BC90`. Для каждого описано конкретное затруднение,
а не общий статус «не проверено». Подробный журнал: [card-content-issues.jsonl](card-content-issues.jsonl).

Карточка публикуется обычной production-сборкой; чтение dev/ сайту не требуется.
Удаление поля снимает значок после пересборки. Ввод чужой HTML-разметки
отображается как обычный текст. Механизм `materialVersion` остаётся прежним.
