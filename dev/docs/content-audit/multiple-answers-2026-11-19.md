# Карточки с несколькими ответами · проверка 19 ноября 2026 года

Проверены 62 дополнительные строки ответа для 44 карточек. ФИПИ принял 55 и отклонил 7. Дополнительные ответы найдены у 41 карточки. Для 38 из них альтернатива подтверждена впервые, ещё у трёх расширился уже известный набор. С учётом 12 прежних карточек в проекте теперь есть свидетельства для **50 карточек с несколькими ответами**.

20 ноября обе партии вошли в объединённый журнал и локальную сборку. Колонки таблиц ниже показывают результат на дату проверки 19 ноября.

## Область поиска

В №1 проверялись открытые пропуски, где иная форма сохраняет нужную часть речи и связь предложений. В №6 проверялась замена одного слова с сохранением согласования и управления. В №25 поиск ограничен указанными в условии предложениями. Кандидаты отбирались по списку оборотов ФИПИ и по контексту, включая личные формы глагола. [Список ФИПИ, с. 6–11](../../../data/sources/fipi-lexicon-2025.pdf#page=6).

Исходная точка — варианты, уже принимаемые тренажёром. Статус ниже относится к точной строке и GUID карточки. Для каждой новой строки сохранены время, код HTTP, тело ответа и его хеш. Использовалась выгрузка заданий проекта, актуальный текст на сервере заново не сравнивался. Поиск выборочный. Новые строки записаны для последующего импорта.
