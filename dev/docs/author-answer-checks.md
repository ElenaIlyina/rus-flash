# Проверка вторых ответов на ФИПИ

Обновлено **29.10.2026**. Одна очередь, максимум три карточки в активной
партии. От автора нужен только результат сервера, не обоснование ответа.

**Сначала сопоставить с новой выгрузкой и логом подбора.** Таблица ниже —
первая подготовленная партия кандидатов. Уже проверенные варианты снимаются
без повторного задания автору; отсутствующие ID не разыскиваются бесконечно.
До сверки с файлами новая ручная проверка не требуется.

| Проверка | Код | Текущий ключ проекта | Второй ответ | Почему проверяем | Результат |
|---|---|---|---|---|---|
| ALT-001 | 09C71B | позже | **затем** | «Сначала в царской, … в Красной армии»; требуется наречие времени, а в почти том же контексте 12BBAB ключ «затем» | Ожидает сверки с выгрузкой/логом |
| ALT-002 | 12BBAB | затем | **позже** | Обратная проверка близкого контекста; принятие в одном ID не доказывает приём в другом | **Отклонён ФИПИ**, по сообщению автора 29.10.2026; проверка альтернативы закрыта |
| ALT-003 | 432ADD | но | **а** | Одна группа нервов ускоряет сердцебиение, другая замедляет; «а» грамматически передаёт противопоставление | Ожидает сверки с выгрузкой/логом |

Формат короткого ответа, когда проверки понадобятся:

```text
ALT-001 — принят
ALT-002 — не принят
ALT-003 — не нашла
```

«Не нашла» или ошибка запроса — не доказательство, что ответ отвергнут.
Для принятого варианта сохраняем связь с исходным JSON и порядком вариантов.
До подтверждения сервера эти ответы **не добавляются** в автопроверку.

Следующая партия сейчас не назначена. Новые предложения не создают новых
обязательств для автора, пока не закрыта текущая партия и не устранено
дублирование с её уже выполненным подбором.

## Автоматизация вместо ручной работы

По последующему предложению автора проверки выполняет
[скрипт](../scripts/check_fipi_answers.py). В начальный план добавлена гипотеза
«неизбежность» для полученного сырого образца 005141. Она не объявляется
принятой до реального ответа 3. Лимит трёх относится к ручной очереди,
а не к автоматической обработке банка. Ни одна из очередей не блокирует
основную подготовку №1–4.

## Результат ALT-002

29.10.2026 автор уточнила: в запуске проверяющего скрипта для `12BBAB`
(GUID `954464872E2690EF4F1F2C22F367D3F3`) отклонён именно ответ **«позже»**.
Основание записи — сообщение автора; машинный JSON-журнал пока не получен.
Альтернатива не добавляется в допустимые ответы. Ключ **«затем»** сохраняется;
это сообщение не считается новым подтверждением его приёма сервером.
Исходный план проверки сохранён без изменений, чтобы продолжение уже начатого
запуска через `--resume` оставалось совместимым. Повторно вручную проверять
«позже» для этой карточки не требуется.
