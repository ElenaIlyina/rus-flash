## Запуск автором

Скачать обновлённый `check_fipi_answers.py` в `src`, затем из папки с `src`:

```bash
python3 src/check_fipi_answers.py --cards src/cards --pending-only --insecure
```

Один Python-файл, без дополнительных пакетов и без скачивания отдельного плана.
`--insecure` соответствует используемому автором `curl -k`; флаг не включается
автоматически. Паузы остаются: 0,5 с между запросами и 10 с после каждых 20.
Файл результата сохраняется в `fipi-results/` вне репозитория.

Продолжение после остановки:

```bash
python3 src/check_fipi_answers.py --cards src/cards --pending-only --insecure --resume fipi-results/ИМЯ-ФАЙЛА.json
```

Новая очередь имеет свой план и журнал. Старые режимы `--new-only`,
`--alternatives-only` и обычный режим не изменены; старые запуски продолжаются
с теми же параметрами. Внутри репозитория результаты по умолчанию пишутся в
`dev/generated/`. Если изменится исходник, проверка откажется смешивать версии.

## Воспроизведение разработчиком

```bash
python3 dev/scripts/prepare_pending_fipi_checks.py \
  --report dev/data/fipi-results/2026-10-29-first-run/report.json \
  --cards dev/generated/fipi-raw-2026-10-29/cards \
  --plan dev/data/fipi_new_hypotheses.json \
  --plan dev/data/fipi_remaining_hypotheses.json \
  --output dev/data/fipi_pending_checks.json \
  --ledger dev/data/fipi-results/2026-10-29-first-run/validated-ledger.json
python3 dev/scripts/bundle_fipi_checker.py
python3 -m unittest discover -s dev/tests -p 'fipi_*_test.py'
```

Проверены: ответы/ошибки HTTP, cookies, обе паузы, продолжение без повторных
отправок, отсутствие зависимости от репозитория, исключение подтверждённых
карточек и сочинений, полнота всей выгрузки, хеши и кодирование каждой гипотезы.
Отрицательные тесты отклоняют HTTP 403 с телом `3`, подмену тела ответа,
дубли карточек и несовпадение исходника. Локальный HTTP-сервер в тесте проверяет
протокол, а не правильность решений. Новые гипотезы требуют настоящего запуска
автора: облачный прокси по-прежнему возвращает 403.
