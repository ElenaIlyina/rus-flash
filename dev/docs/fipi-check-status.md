## Запуск автором

Скачать обновлённый `check_fipi_answers.py` в `src`, затем из папки с `src`:

```bash
python3 src/check_fipi_answers.py --cards src/cards --pending-only --insecure
```

Один Python-файл, без дополнительных пакетов и без скачивания отдельного плана.
`--insecure` соответствует используемому автором `curl -k`; флаг не включается
автоматически. Паузы остаются: 0,5 с между запросами и 10 с после каждых 20.
Файл результата сохраняется в `fipi-results/` вне репозитория.

Продолжение после остановки:

```bash
python3 src/check_fipi_answers.py --cards src/cards --pending-only --insecure --resume fipi-results/ИМЯ-ФАЙЛА.json
```

Новая очередь имеет свой план и журнал. Старые режимы `--new-only`,
`--alternatives-only` и обычный режим не изменены; старые запуски продолжаются
с теми же параметрами. Внутри репозитория результаты по умолчанию пишутся в
`dev/generated/`. Если изменится исходник, проверка откажется смешивать версии.
