# Список ударений в справочнике

Реализовано 29.10.2026 в ветке `feat/ege-1-6-priority`.

Во всех карточках, сопоставленных с №4, в блоке теории находится ссылка
«Полный список ударений по частям речи». Та же ссылка доступна под разбором;
кнопка «Открыть справочник» ведёт непосредственно к списку. На узком экране
блок теории расположен под упражнением. Из общего справочника список
открывается через «Библиотеку источников».

Адрес: `#knowledge?list=stress`. При переходе из карточки добавляется
`&card=011AA6`, чтобы можно было вернуться к ней. Чтение списка не считается
подсказкой, не сбрасывает номер попытки и не записывает учебный результат.

**Добавлено 30.10.2026:** [отдельный словарик всех форм из карточек](stress-glossary.md)
— 193 формы, 38 групп для сравнения. Исходный список ФИПИ сохранён;
оба материала доступны из карточек №4.

## Содержание и версия

[Структурированные данные](../../data/knowledge/stress-list.json) содержат все
192 строки шести разделов орфоэпического списка из пользовательского PDF:

- существительные — 60;
- прилагательные — 9;
- глаголы — 83;
- причастия и отглагольные прилагательные — 25;
- деепричастия — 7;
- наречия — 8.

Это число строк, а не число отдельных словоформ: в одной строке бывают
несколько форм. Сохранены прописные ударные гласные, грамматические пометы,
смысловое различие «Отзыв / отзЫв» и дополнительные формы после точки с запятой.
Два номера сносок вынесены из строк в `noteIds`; сами примечания доступны
ниже списка. Исключённые слова находятся отдельно и не добавляются в
основные шесть разделов.

Интерфейс указывает «Список ФИПИ · 2026» — год названия списка на с. 1.
Заголовки страниц исходника смешивают 2025/2026, что сохранено в метаданных.
Это весь список данного источника, а не полный орфоэпический словарь русского
языка и не подтверждённая редакция 2027. [Проверка покрытия](priority-1-6/source-coverage.md).

Внизу есть исходный PDF; он доступен с сайта без обращения к ФИПИ.
Сборка проверяет SHA-256 оригинала, затем копирует JSON и PDF в
`html/assets/data/`. Конвертер PDF и сеть для сборки не нужны. Список
загружается только при открытии, PDF — по отдельной ссылке.

Для обновления нужно сохранить новый источник отдельно, проверить состав
слов и версии, заменить структурированные данные и их хеш. Исходные
карточки/ключи не изменяются автоматически.
