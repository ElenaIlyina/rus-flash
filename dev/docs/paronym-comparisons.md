# Паронимы: карточки, сравнения и общий список

После разделения проекта редакторские реестры находятся в `dev/data/`,
сверка и публикация готовых данных — в `dev/scripts/publish_content.py`.
Основная сборка не читает эти реестры. [Текущая структура](production-separation.md).

Актуально на **29.10.2026**, ветка `feat/ege-1-6-priority`.

## Реализовано

- Все **114 карточек №5** имеют индивидуальную подсказку, объяснение замены,
  исправленное предложение в объяснении, сравнение слов и словарные ссылки.
  112 прежних объяснений заменены; два ранее проверенных сохранены.
- **57 сравнений**, **132 кратких толкования**. Это группы, необходимые
  для объяснения ошибочных словосочетаний, а не определения всех слов списка.
- В справочнике — отдельный **алфавитный список 127 пар и групп**,
  связанных со словами из всех пяти вариантов и ответов. В нём 299 членов
  групп, без толкований и дубликатов. Не каждый партнёр сам встречается
  выделенным: список включает соответствующую ему полную группу.
- Проверены **570 выделенных употреблений и 114 ответов**. Реестр
  [словарных привязок](content-audit/task-5-dictionary-coverage.json)
  хранит ссылки для каждого из пяти вариантов, позицию замены и хеш исходника.
- Теория: `#knowledge?list=paronyms&view=theory`.
  Список: `#knowledge?list=paronyms`. Обе ссылки есть в карточках №5.
- Исходные тексты, варианты, GUID, КЭС, `answer` и `answer_verify` сохранены.
  Оценивание строго следует ключам ФИПИ. Это не новая проверка сервером ФИПИ.

Статус словарной сверки означает прочтение и сопоставление конкретных статей
ассистентом. Независимая предметная приёмка учителем не заявляется.
[Саморевью и ограничения](task-5-self-review.md).

## Контракт данных

`data/knowledge/paronym_inventory.json` содержит 144 группы полученного
списка ФИПИ-2025 и явно сопоставленные формы. `scripts/paronym_inventory.py`
выбирает 127 используемых групп, проверяет каждое выделение и однозначно
находит позицию замены по группе ответа. Unicode приводится к NFC без
изменения исходников. «США» в 37859F явно исключено как аббревиатура страны.
Источник состава групп — 2025 год, его не выдаём за финальный список 2027.

`dev/data/knowledge/paronyms.json`:

- `sources`: оригиналы, SHA-256, подтверждённые выходные данные, формат;
- `pairs`: стабильный ID, `words`, `distinction`, `curriculumRef`, `reviewStatus`;
- у слова: `meaning`, два учебных примера, `dictionaryRefs`;
- PDF-локатор: `dictionaryId`, `headword`, `pdfPage`; неизвестный
  `printedPage` равен null;
- MOBI-локатор: `dictionaryId`, `headword`, `entryId`. Страницы не выдумываются;
- `definitionQuote`, метод и дата чтения — редакторские основания;
- `omittedMembersWithoutDictionaryArticle` — только редакторский список
  недостающих статей, не статус для ученика.

`ege_1_6_card_reviews.json` связывает карточки и сравнения через
`paronymPairIds`, фиксирует подсказку, хеш неизменных полей и объяснения.
`dictionaryReview.status=verified` допускает публикацию пояснения.

Краткие значения — сокращённый пересказ прочитанных статей, не полный
словарь. Учебные сочетания могут быть составлены для иллюстрации значения;
они не выдаются за дословные цитаты. Дословные основания хранятся отдельно.
Многозначность, переносность и пересечения значений не исключаются.

## Сборка и интерфейс

`paronym_sources.py` проверяет хеши оригиналов и извлечённых статей,
существование локаторов, границы PDF-страниц и вхождение цитат в прочитанный
текст. Для первоначальных визуально проверенных ссылок сохранён отдельный
метод `visual_page_read`. Проверки структуры не заменяют чтение источника.

PDF открываются по `#page=N`. Для MOBI публикуются только 56 выбранных
текстовых статей, открываемых в справочнике. Оригинал MOBI (15,3 МБ) не входит
в веб-ресурсы. Его HTML, JavaScript и обработчики событий не исполняются.
Текст статьи выводится через экранирование. PDF и электронные статьи
загружаются при обращении. Цитаты и сведения о подготовке не передаются
в начальном каталоге приложения.

Сначала показывается объяснение конкретного предложения, затем сравнение.
На узком экране слова расположены друг под другом. Открытие разбора или
подсказки считается помощью; самостоятельное чтение теории — нет.
Возврат из теории и локальной словарной статьи ведёт в исходную карточку.

## Оставшиеся ограничения

В трёх полученных словарных копиях не найдены самостоятельные толкования
**«нетерпеливый»** и **«информационность»**. Они включены в общий список по
ФИПИ, но их определения не придуманы. В 57 сравнениях эти два члена групп
опущены. Сами они не являются выделенными словами или ответами текущих
114 упражнений; разборы реально проверяемых пар обеспечены источниками.
Нужны точные статьи с выходными данными и устойчивыми ссылками.

Год и редакция пользовательского MOBI Ожегова—Шведовой не установлены:
тождество изданию из кодификатора не утверждается. Есть спорные/пересекающиеся
контексты, записанные в [очередь замечаний](content-audit/open-issues.md).
Ни один из них не меняет ключ или блокирует проверку по решению автора.

Проверки: `paronym_sources_test.py`, `paronym_inventory_test.py`,
`priority_1_6_smoke.py`, `paronyms_smoke.py`, `content_audit_test.py`,
`bank_knowledge_smoke.py`, `check_pages_artifact.py`.
