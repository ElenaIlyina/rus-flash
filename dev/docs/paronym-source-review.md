## Найденная неоднозначность 012CAB

В исходнике: «Изящное деревянное изделие покрыто ЛАКИРОВАННЫМ раствором».
Сохранённые `answer` и `answer_verify`: **ЛАКИРОВОЧНЫМ**.

На с. 574 первого словаря в значении 1 слова «лаковый» явно дан пример
**«Лаковый раствор»**. Поэтому возможный дополнительный ответ **«лаковым»**
нельзя считать лексически ошибочным только потому, что он отличается от
сохранённого ключа. Ни «дополнительный ответ принят ФИПИ», ни «ключ ФИПИ
ошибочен» по одному словарю не утверждаются.

Заведено **PARONYM-ANSWER-001**. По последующему решению автора от 29.10.2026
автоматическая проверка работает строго по сохранённому ключу ФИПИ:
**«лакировочным» засчитывается, «лаковым» не засчитывается**. Временная
блокировка проверки и закрепления снята; ключ не расширен и не заменён.

В объяснении сохранено, что «лаковый раствор» допустимо по словарю.
Лексическая допустимость не равна наличию ответа в ключе конкретного
экзаменационного задания. Словарное примечание не меняет оценивание.
01C2C7 также проверяется по своему сохранённому ключу.

эта копия используется для значений, не для проверки ударений.

## Восстановление текста первого PDF

Обычное извлечение повреждает буквы из-за таблицы ToUnicode. Текст восстановлен
по Unicode cmap встроенного шрифта и фактическому glyph ID; языковые догадки
и исправление «по смыслу» не применялись. Затем прочитаны статьи, сверены
заголовки и фактические страницы. Примеры визуального чтения указаны выше.

Подготовительный инструмент `dev/scripts/content/recover_normative_paronyms.py`
принимает PDF и каталог результата. Нужны PyMuPDF и fontTools; для сборки сайта
они не нужны. Прочитанные фрагменты сохранены рядом с оригиналами как
`read-articles.json`. Для Вишняковой использован читаемый текстовый слой PDF.
Методы в реестре различаются: визуальное чтение, чтение восстановленного
текста встроенных шрифтов, чтение текста электронного PDF, электронной статьи.
Это редакторская сверка, не автоматическое доказательство правильности.

## Публикация и ограничения

114/114 разборов допущены к публикации; 57 сравнений, 132 кратких толкования.
Для всех пяти вариантов каждой карточки сохранены словарные локаторы.

Они перечислены в отчёте саморевью и очереди замечаний.
