# Предметная модель

> Состояние на 26.10.2026: Описана целевая модель. Сейчас data.js адаптирует прежние JSON; общих passageId, полного каталога навыков и версионируемого редакторского контента ещё нет.

## Основные сущности

| Сущность | Смысл и обязательные связи целевой модели | Статус |
|---|---|---|
| Card | Постоянный ID, версия, условие, response, проверяемые навыки, review; необязательный passageId | Согласовано |
| Passage | Отдельный исходный текст, автор/источник, версия, абзацы/предложения со стабильными ID | Согласовано |
| Rule | Правило, примеры, исключения, источник/редакция, статус проверки | Согласовано |
| Skill | Конкретное умение, описание результата, связи предпосылок | Согласовано |
| ExamMapping | Соответствие навыка/карточки экзамену, году, номеру задания и источнику подтверждения | Согласовано |
| Route | Версионируемый граф этапов выбранного направления | Согласовано |
| Stage | Цель этапа, целевые навыки, предпосылки, правила, упражнения | Согласовано |
| LearningEvent | Неизменяемое действие пользователя: попытка, показ подсказки/ответа, самооценка и др. | Предлагается |
| LearnerSkillState | Вычисляемая проекция истории на навык, с версией алгоритма и объяснением | Согласовано |
| SelfAssessment | Отдельная самооценка ученика, не системный статус | Согласовано |
| StudyModule | Зафиксированный набор материалов, навыков и целей конкретного маршрута/исследования | Предлагается |

**DOM-01 · Согласовано.** ID карточки не является номером ЕГЭ или уровнем сложности. Текущая нумерация групп не подтверждает соответствие ЕГЭ-2027.

**DOM-02 · Согласовано.** Card не содержит прогресс конкретного ученика. Отметки, попытки, самооценка и расписание повторения хранятся отдельно.

**DOM-03 · Согласовано.** Один Passage может использоваться несколькими карточками. Условие карточки и варианты ответа не помещаются в исходный текст. Нумерация предложений и смысловые выделения сохраняются.

**DOM-04 · Предлагается.** Разметка Passage: абзацы → предложения/фрагменты → `runs: [{text, marks}]`. Marks: bold, italic, underline, sub, sup. Произвольные HTML/JS/обработчики событий запрещены. Учебные подсветки — отдельные аннотации со ссылками на фрагменты, не изменение оригинала.

**DOM-05 · Согласовано.** Card связывается с несколькими навыками при необходимости. Связь означает «участвует в решении», но не «любая ошибка доказывает незнание этого навыка».

**DOM-06 · Предлагается.** `assessmentTargets` задаёт, какие навыки можно оценить по результату задания. Комплексное экзаменационное задание без диагностического ключа даёт историю практики, но не автоматически положительное/отрицательное свидетельство по всем связанным навыкам.

## Проверка и происхождение

Для условия, ответа, объяснения и классификации — независимые review-записи:

```json
{
  "status": "draft",
  "reviewerId": null,
  "reviewedAt": null,
  "sourceRefs": [],
  "materialRevision": 1
}
```

**DOM-07 · Предлагается.** Статусы качества: missing, draft, verified, withdrawn. verified требует проверяющего, времени и версии материала; наличие строки ответа не достаточно. Обоснование withdrawn обязательно. Машинная генерация не присваивает verified.

**DOM-08 · Предлагается.** Версия карточки повышается при смысловом изменении условия, вариантов, эталона или разметки навыков. Косметическое исправление оформления, не меняющее смысл, фиксируется отдельно. Сведения об источниках не подменяются ссылкой на модель.

## Термины, которые нельзя смешивать

- **Совпадение с базой** — результат текущей строковой проверки, не доказательство правильности базы.
- **Самостоятельная попытка** — по правилам ASM-02; скорость ответа не является критерием.
- **Изучено** — ручная отметка, не оценка знания.
- **Получается** — системное заключение о конкретном навыке, не вся тема и не экзаменационная оценка.
- **Полнота контента** — наличие и проверенность материалов.
- **Полнота маршрута** — покрытие заявленных учебных целей этапами.
- **Прогресс ученика** — его действия и подтверждённые результаты относительно выбранной версии модуля.
