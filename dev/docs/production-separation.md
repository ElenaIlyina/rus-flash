# Разделение приложения и вспомогательных материалов

**29.10.2026**, ветка `feat/ege-1-6-priority`.

## Границы

| Основная часть | Вспомогательная часть `dev/` |
|---|---|
| Интерфейс `html/` | Планы, спецификации, литература и согласования `dev/docs/` |
| 2140 исходных карточек `data/card_*.json` | Баги, журналы, ревью и саморевью `dev/docs/` |
| Подготовленные правила, подсказки и связи `data/knowledge/` | Полные редакторские реестры `dev/data/` |
| PDF и статьи, которые читает ученик `data/sources/` | Оригиналы, нужные только для подготовки/аудита, и извлечённые доказательства |
| Сборка и проверка публикации `scripts/` | Получение и проверка ФИПИ, импорт PDF/MOBI, старый классификатор `dev/scripts/` |
| GitHub Pages `.github/workflows/` | Все тесты `dev/tests/`, отдельная страница ревью `dev/review/` |

Не всё справочное является вспомогательным. PDF, открывающиеся по учебным
ссылкам, выбранные статьи словаря, FB2 для генерации параграфов и необходимые
поправки к нему остаются в основной части. Оригинал MOBI, не открывающийся
на сайте и нужный только для аудита/нового извлечения, находится в `dev/`.
Текущие ограничения автопроверки — часть поведения приложения, поэтому
сохраняются в `data/assessment_policy.json`; журнал причин остаётся в `dev/`.
Для 682A9C подробное редакторское замечание заменено в приложении коротким
сообщением о недоступности проверки; подробности сохраняются только в dev.

## Подготовка и сборка — два этапа

`dev/scripts/publish_content.py` проверяет редакторские записи и создаёт
шесть подготовленных входов:

- `data/knowledge/card_support.json`: 220 записей с готовыми подсказками,
  связями и хешами карточек; без статусов автора и журнала ревью;
- `data/knowledge/paronyms.json`: только опубликованные сравнения и значения;
- `data/knowledge/dictionary_sources.json`: файлы учебных источников и их хеши;
- `data/knowledge/source_registry.json`: необходимые сведения для генерации параграфов;
- `data/exam_profile.json`: год, статус проекта и названия позиций;
- `data/assessment_policy.json`: действующие ограничения проверки.

Оригинальные редакторские данные сохранены в `dev/data/`, а не заменены этими
проекциями. `--check` у инструмента проверяет синхронность без записи.

`bash scripts/install.sh` читает только основную часть. Не требуется полный
MOBI, документация, тесты, журналы или сторонние Python-пакеты. Сборка
пересоздаёт игнорируемый каталог `html/assets/data/`, удаляя устаревшие
отладочные файлы. `check_pages_artifact.py` отклоняет их присутствие.

Старый `generate_manifest.py` теперь относится к разработке и пишет
результат в игнорируемый `dev/generated/`, а не в приложение. Получение новых
карточек и подтверждение ключей через ФИПИ не вызываются штатной сборкой.

## Ревью

Код, CSS, данные и управление ревью вынесены из ученического сайта.
В полном клоне запускается `python3 dev/scripts/build_review_data.py`,
затем HTTP-сервер корня проекта. Страница `/dev/review/` показывает очередь,
замечания, локальное принятие и само приложение в iframe.

Сохранены все 31 запись и их прежние версии. Ключ локального принятия
`slovo_review_acceptances_v1` не менялся. Старый флаг включения отладки
не включает ничего в production. Нажатие принятия не создаёт учебных событий.
[Инструкция](review-debug.md).

## Чистое скачивание и деплой

`.gitattributes` содержит `/dev export-ignore`: `git archive` и исходные
архивы GitHub не включают вспомогательный каталог. Полный `git clone`
сохраняет разработку и историю. Корневой README содержит только инструкции
сборки, использования и публикации; инструкции разработки — в `dev/README.md`.

Workflow GitHub Pages остаётся ручным и публикует только `html/`.
Перенос не запускает деплой и не меняет настройки GitHub environment.

## Проверка сохранности

Перед переносом сохранён локальный снимок сборки. После разделения:

- все 2140 публичных карточек совпали по значениям всех полей;
- совпали ключи, допуск к оценке, подсказки, учебные ссылки и версии материалов;
  единственное изменённое предупреждение — понятный ученику текст 682A9C;
- совпали сравнения паронимов в части слов, значений, примеров и ссылок;
- совпали все 31 запись очереди и их версии;
- исходные `data/card_*.json` не изменялись.

Следовательно, это разделение не сбрасывает учебные оценки и охват.
Неиспользуемые диагностические поля исключены из каталога: его размер
уменьшился с 2 170 592 до 1 960 980 байт. Это не изменение содержания карточек.

`production_separation_test.py` проверяет актуальность подготовленных входов
и отсутствие ревью в ученическом сайте. Он создаёт копию только основной
части, удаляет готовый результат и запускает сборку с `python -S`: без `dev/`
и site-packages. Повторная сборка удаляет подложенный устаревший debug-файл.

Дополнительно проверяется чистый ZIP из индексированного дерева Git:
в нём нет `dev/`, после распаковки работают сборка и проверка публикации.

Проверки: 34 модульных теста; основные браузерные сценарии, настройки,
прогресс/перенос, знания, 189 подготовленных карточек, списки, главная,
отдельное ревью и публикация в подкаталоге. Обнаруженное устаревшее ожидание
в `ui_smoke.py` заменено на уже реализованный переход №5 к списку паронимов,
без изменения навигации приложения.
