## Веб-модули

| Что делает ученик | Где искать реализацию |
|---|---|
| Открывает карточку и отвечает | `app.js` выбирает экран, `data.js` загружает карточку и определяет тип ответа, `assessment.js` сверяет ввод с эталоном. |
| Смотрит прогресс и продолжает практику | `store.js` записывает попытки, `learning.js` рассчитывает оценки по настройкам, `bank-order.js` задаёт порядок, `adaptive.js` рекомендует следующую карточку. |
| Переносит историю карточек | `progress-transfer.js` проверяет файл и объединяет записи. |
| Решает учебный вариант | `exam.js` подбирает комплект и считает баллы. `exam-page.js` управляет экраном и отдельно сохраняет прохождение. `exam-theory.js` содержит теорию по номерам. |
| Открывает справочник | `knowledge.js` выбирает раздел, `data.js` загружает материалы. Общие функции показа текста находятся в `ui.js`. |

## Направление зависимостей

```mermaid
flowchart LR
  Editorial["dev/: доказательства и редакторские реестры"] --> Publish["dev/scripts/publish_content.py"]
  Publish --> Data["data/: подготовленные учебные данные"]
  Data --> Build["scripts/build_app_data.py"]
  Build --> Runtime["html/assets/data/"]
  Runtime --> App["Приложение"]
  Runtime --> Workbench["dev/review/: отдельное ревью"]
```

Обратной зависимости от production к `dev/` нет. Скрипты получения новых
заданий, проверки ФИПИ, извлечения PDF/MOBI и тесты не нужны пользователю сайта.
При изменении учебных материалов обновляются подготовленные данные через
редакторский инструмент, затем запускается штатная сборка.

[Проверка разделения](production-separation.md), [инструмент ревью](review-debug.md).
