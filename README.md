# Слово за слово

Статический тренажёр русского языка: 2140 карточек, задания по темам,
подсказки, объяснения и справочник, прогресс карточек и тем.
Позиции заданий сопоставлены с официальным проектом ЕГЭ-2027;
прежние форматы отмечаются в приложении.

## Запуск на Ubuntu

Нужны Python 3.9+ и современный браузер. Сборка не требует npm, сторонних
Python-библиотек, подключения к ФИПИ, ключей API или серверной базы данных.

Клонируйте репозиторий:

```bash
sudo apt update
sudo apt install -y git python3
git clone https://github.com/ElenaIlyina/rus-flash.git
cd rus-flash
```

Если нужна рабочая ветка, выберите её перед сборкой. Из каталога проекта:

```bash
bash scripts/install.sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory html
```

Откройте `http://127.0.0.1:8000`. Остановить сервер — Ctrl+C.
Открытие `index.html` через `file://` не поддерживается: данные читаются через fetch.

## Состав приложения

```text
data/                     Карточки, учебные материалы, готовые подсказки и ссылки
  sources/                PDF и извлечённые статьи, используемые справочником
  knowledge/              Правила, словники и данные для объяснений
html/                     Интерфейс приложения
  assets/data/            Генерируется при сборке, в Git не хранится
scripts/                  Только сборка и проверка комплекта для публикации
.github/workflows/        Деплой GitHub Pages
```

`bash scripts/install.sh` воспроизводит `html/assets/data/` из подготовленных
данных. Исходные карточки не переписываются. Каталог `html/` после сборки
можно разместить на статическом хостинге.

Каталог `dev/` также хранится в Git. В нём находятся материалы разработки,
планы, тесты, ревью и инструменты подготовки. Сборка приложения использует
только `data/`, `html/` и `scripts/`; GitHub Pages публикует только `html/`.

## Разделы и прогресс

| Адрес | Содержимое |
|---|---|
| `#study` | Главная и выбор темы |
| `#bank` | Банк заданий, поиск, фильтры и избранное |
| `#card/EECA69` | Карточка, проверка, подсказка и объяснение |
| `#progress` | Охват, закрепление и история |
| `#knowledge` | Правила, словари и списки |
| `#settings` | Порог, коэффициенты оценок и срок повторения |

Прогресс и настройки хранятся в браузере. «Скачать прогресс» и «Загрузить
прогресс» переносят историю между устройствами через JSON; файл не уходит
на сервер. Чтение теории не считается подсказкой. Правильный ответ с n-й
отправки получает 1/n, с подсказкой или просмотром ответа — 0.

## GitHub Pages

1. В **Settings → Pages → Source** выберите **GitHub Actions**.
2. Для environment `github-pages` разрешите публикацию выбранной ветки.
3. Во вкладке **Actions** откройте **Deploy Slovo za Slovo to GitHub Pages**.
4. Нажмите **Run workflow** и выберите нужную ветку.

Workflow использует Python 3, собирает карточки и публикует только `html/`.
Пуш сам по себе деплой не запускает. Локальная проверка комплекта:

```bash
python3 scripts/check_pages_artifact.py html
```
