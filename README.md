# «Слово за слово» — русский шаг за шагом

Статический тренажёр по русскому языку с банком из 2140 карточек ФИПИ. Новый адаптивный интерфейс: занятия, поиск по банку, карточки, локальная история попыток, избранное и экспорт прогресса.

**Версия для ревью интерфейса.** Ответы, разборы и классификация ещё требуют предметной проверки. Наличие ответа в базе не означает редакторского подтверждения. Позиции сопоставлены с официальным проектом ФИПИ-2027; старые форматы и неоднозначные случаи отмечены отдельно. RAG, полная нормативная база правил, полноценный адаптивный маршрут, серверная синхронизация и PWA пока не подключены.

## Локальный запуск на Ubuntu

Нужны Git, Python 3 и современный браузер. npm, сторонние Python-библиотеки и ключи для работы приложения не нужны.

```bash
sudo apt update
sudo apt install -y git python3
git clone https://github.com/ElenaIlyina/rus-flash.git
cd rus-flash
git switch feat/slovo-za-slovo
bash scripts/install.sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory html
```

Откройте в своём браузере адрес `http://127.0.0.1:8000`. Это адрес сервера на вашей машине, не публичная ссылка. Остановить сервер: Ctrl+C. Новый интерфейс использует fetch и требует HTTP, открытие index.html через file:// не поддерживается.

Для нового интерфейса достаточно отдельной сборки данных:

```bash
python3 scripts/build_app_data.py
```

После изменения JSON повторите сборку. Генератор не меняет исходники: создаёт каталог и отдельный JSON каждой карточки в игнорируемом `html/assets/data/`. Карточки загружаются по одной; главный экран не скачивает весь банк условий и текстов. Для размещения нужно опубликовать содержимое `html/` вместе с результатами сборки. Для уменьшения передачи включите gzip/Brotli на статическом хостинге.

## Что можно проверить

- Четыре раздела и адаптивная навигация на телефоне и компьютере.
- Поиск по тексту/ID, фильтры групп, наличия ответа, избранного и повторения; порционная выдача.
- Отдельные текст и вопрос, сохранение ограниченной разметки, чекбоксы для явно заданного bitmask-типа и ввод краткого ответа.
- Проверка по существующему ответу, показ исходного разбора, ручные метки.
- История новых попыток: самостоятельная, с открытым ответом или повторная после обратной связи.
- Скачивание и загрузка JSON-прогресса с предварительным просмотром и объединением истории.
- Реальные предварительные статусы и прогресс по группам; стратегия-подсказка с учётом помощи.
- Явные состояния отсутствующих правил, адаптивного маршрута и синхронизации.

Старые метки `task_tags_<ID>` сохраняются, избранное и «повторить» доступны в новом UI. Старое `solved` не становится новой подтверждённой попыткой. «Изучено» — отдельная ручная отметка. Прогресс привязан к origin браузера (протокол, хост, порт). Изменение порта или очистка браузера создают отдельное состояние. Серверу история не отправляется.

```text

html/js/ui.js                 иконки и безопасное форматирование текста
html/js/learning.js           детерминированная экспериментальная политика
html/js/progress.js           реальные статусы и прогресс
html/js/hints.js              стратегии-подсказки без ответов
html/js/adaptive.js           первый подбор с причиной
html/js/bank-order.js         порядок банка
html/js/assessment.js         политики проверки ответов
html/js/data.js               загрузка и адаптер существующей модели
html/js/store.js              локальные попытки, метки, экспорт
html/js/services.js           контракты будущих правил, адаптации и синхронизации
html/assets/data/             генерируемый каталог и карточки, не хранится в Git
scripts/build_app_data.py     данные для нового интерфейса
scripts/exam_2027.py          сопоставление позиций официальному проекту
scripts/audit_verified_cards.py  реестр ответов и изменений позиций
scripts/generate_manifest.py  классификатор; старый манифест только для утилит
scripts/parse_fipi_missing.py загрузка ФИПИ
scripts/verify_answers_fipi.py  проверка ответов ФИПИ
scripts/restore_fipi_highlights.py  восстановление выделений
tests/ui_smoke.py             функциональные браузерные проверки
docs/development-plan.md      подробный продуктовый и исследовательский план
docs/interface-review.md      границы реализации и маршрут ревью
docs/ui-preview/              снимки интерфейса
```

Сетевые утилиты ФИПИ не нужны для запуска. TLS-проверка сертификатов включена; сетевой прогон зависит от доступности ФИПИ и прокси. Обычная сборка не делает внешних запросов.

## Проверки

```bash
bash scripts/install.sh
python3 scripts/check_pages_artifact.py html
python3 tests/ui_smoke.py
python3 tests/content_audit_test.py
python3 tests/learning_smoke.py
# Обновить снимки для ревью:
python3 tests/ui_smoke.py --screenshots
```

Для браузерного теста отдельно нужны Python Playwright и Chromium. Они не являются зависимостями приложения. В этой облачной среде уже установлены. На Ubuntu можно подготовить их в виртуальном окружении:

```bash
sudo apt install -y python3-venv chromium
python3 -m venv .venv
.venv/bin/pip install playwright
.venv/bin/python tests/ui_smoke.py
```

Тест по умолчанию использует `/usr/bin/chromium`. Он запускает временный HTTP-сервер, изолированные браузерные контексты и не меняет исходные карточки. На системах без этого пути необходимо указать фактический исполняемый файл в тесте.

## Название

Публичное название — **«Слово за слово»** (английский вариант: Word by Word). Переименование подготовлено в ветке `feat/slovo-za-slovo`. Название репозитория `rus-flash`, адрес Pages и технический ключ `rusflash_learning_v1` пока сохранены: они не являются отображаемым брендом, а сохранение ключа предотвращает потерю существующего прогресса. Исторические снимки в документации могут показывать прежнее название; это артефакты предыдущих ревью. Компоновка страницы из выбранных модулей четырёх вариантов — следующий этап после указаний владельца.


## Сборка главной из выбранных модулей

Главная собрана по коллажу: компактная навигация, заголовок и счётчики слева, постер «Ё!» справа, четыре тематические заметки в стиле «Студии». [Описание, снимки и проверка](docs/composed-home.md). Реальная история доступна в прогрессе отдельной кнопкой; демонстрационный дашборд остаётся явно обозначенным.


## Перенос прогресса между устройствами

В заголовке «Мой прогресс» доступны **«Скачать прогресс»** и **«Загрузить прогресс»**. JSON сохраняет настоящие попытки и метки этого браузера, без демонстрационных процентов. Загрузка проходит локально: файл не отправляется на сервер. После проверки и предварительного просмотра подтвердите объединение; текущая история не удаляется, дубликаты попыток не добавляются. [Контракт переноса](docs/specification/progress-transfer.md). Автоматической синхронизации аккаунта пока нет.

## Как ориентироваться в веб-коде

Приложение имеет одну оболочку `html/index.html`; экраны и обработчики находятся
в `html/js/app.js`. Навигация использует `#study`, `#bank`, `#card/ID`,
`#progress`, `#knowledge`. Работа с данными, хранилищем, переносом прогресса
и демо-дашбордом вынесена в отдельные JS-модули. `services.js` сохраняет точки
подключения будущих правил, адаптации и синхронизации.

Порядок CSS задан в `app.css` и важен для каскада:

- `base.css` — общие переменные, навигация и кнопки;
- `study.css` — базовые блоки главной и тематические карточки;
- `bank-card.css` — поиск, банк и упражнения;
- `history-knowledge.css` — реальная история, справочник, диалоги;
- `responsive.css` — общие адаптивные правила и уменьшение движения;
- `progress.css` — демонстрационный дашборд;
- `home.css` — выбранная композиция главной, notes, постер и логотип.

Старые страницы сравнения и статистики удалены из веб-каталога; их исходники
остаются в истории Git. Обычная сборка больше не создаёт старые HTML-карточки
и `cards_manifest.js`. Утилита verify_answers_fipi.py выбирает группы напрямую через exam_2027.py.
Старый generate_manifest.py сохраняет классификатор для сравнения «до/после»
и необязательную диагностическую команду; текущему UI манифест не нужен. В сохранившейся рабочей папке после прежних сборок могут
оставаться игнорируемые `html/cards/card_*.html` и `html/cards_manifest.js` —
они больше не используются; чистый checkout их не содержит.

## Проверка материалов и реальные статусы

[Официальная таблица позиций-2027](docs/ege-2027-card-mapping.md) содержит
ссылки, страницы и сохранённые PDF проекта ФИПИ. [Журнал исправлений](docs/correction-log.md)
фиксирует причины и файлы; изменения позиций по ID находятся в docs/content-audit/position-changes.jsonl.
Реальные статусы, знаменатели, версии материалов и ограничения описаны
в [контракте текущей политики](docs/current-learning.md). На #progress теперь
реальные данные; демонстрация остаётся по #progress?view=preview.
Новая политика экспериментальная, не валидированная педагогическая методика.
